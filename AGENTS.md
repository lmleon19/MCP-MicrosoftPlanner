# Instrucciones del proyecto

## Inicio

Si existe `skills/configuracion-proyecto/configuracion-proyecto.yml`, carga `00-cplt-flujo-trabajo` y la skill local `configuracion-proyecto`. Ese YAML es la fuente de verdad del contexto y de la configuración operativa del repositorio.

Si no existe, el repositorio está en inicialización: carga `01-cplt-inicio-proyecto-dotnet` antes de realizar otro trabajo.
